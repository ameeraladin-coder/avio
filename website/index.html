Install

Ready in a minute

  1. Click Download for Windows and open Avio-Setup-1.2.2.exe.
  2. Keep the internet on. The small installer fetches the rest of Avio (about 100 MB).
  3. Look for the yellow icon next to the clock, select a file and tap Ctrl twice.
